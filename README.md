# C++ TCP Device Control

An academic C++ project developed as part of my Computer Science coursework at SUNY Broome Community College.

## About the Project

This project demonstrates communication between a C++ application and an external TDB hardware module using TCP/IP sockets.

The application uses Windows Sockets (Winsock) to establish a TCP connection with the device and send commands to control LED outputs.

As part of the project, I also used Wireshark to capture and analyze the network traffic generated between the application and the device.

## Features

- TCP/IP socket communication
- Connection to an external hardware module
- Sending commands from C++ to hardware
- LED output control
- Network traffic analysis using Wireshark
- Command-line port configuration

## Technologies

- C++
- TCP/IP
- Winsock
- Wireshark
- Visual Studio
- Computer Networking
